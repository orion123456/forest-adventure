# Forest Adventure

Одноуровневый браузерный платформер. Лес папоротников состоит из четырёх участков, 19 пропастей, 20 монет, восьми слизней и четырёх летучих мышей. Флаг на опушке завершает уровень при любом счёте. Игра работает локально и не загружает внешние ресурсы во время прохождения.

## Запуск

Нужен Node.js 22.12+ в ветке 22 или совместимая версия Node.js 24+.

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Стрелки **← →** управляют бегом, **↑** запускает прыжок, **Пробел** стреляет, **Esc** переключает паузу. Удерживайте пробел, чтобы стрелять с интервалом 350 мс.

## Проверки

```sh
npm run build
npm test
npx playwright install chromium
npm run test:e2e
```

Для проверки в установленном Google Chrome используйте `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`. Полный маршрут занимает около полутора минут. В E2E-режиме тестам доступно чтение координат и состояния сцены. Уровень проходится клавишами через обычный игровой цикл.

## Код

```text
src/
  main.tsx
  app/       React-меню, HUD, результаты и CSS Modules
  assets/    оригинальные SVG и генерация кадров спрайтов
  game/
    config.ts      логическое разрешение, движение и бой
    level.ts       тип Level и карта первой главы
    session.ts     состояния попытки и подписка React/Phaser
    entities.ts    игрок и патрульные враги
    scenery.ts    окружение, платформы, шипы и параллакс
    LevelScene.ts  Arcade Physics, столкновения и игровой цикл
tests/
  unit/      правила попытки и конфигурация карты
  e2e/       управление, перезапуски, бой и полный маршрут
```

Передайте её в `mountGame` и используйте её же для счётчика монет и подписи главы в React. Сцена, физика, управление и правила попытки переиспользуются. Для другой темы добавьте ресурсы и параметры оформления в `assets` и `scenery.ts`.
