# Спецификация Forest Adventure

## 1. Назначение и границы

Forest Adventure — однопользовательский горизонтальный 2D-платформер для настольных браузеров. Игрок управляет путешественником в Лесу папоротников, преодолевает препятствия и добирается до финишного флага. Сбор монет и уничтожение врагов необязательны. Игра работает на клиенте и использует локальные графические ресурсы. В MVP одна глава, клавиатурное управление и игра без звука. Серверная часть, авторизация, сохранения и сенсорное управление вне объёма MVP.

Ориентир прохождения — 90–150 секунд. Это ориентир баланса, таймера обратного отсчёта в игре нет. Проверочный маршрут в Chrome занял 99,7 секунды при непрерывном движении и прыжках по координатам препятствий.

## 2. Состояния и интерфейс

| Состояние | Что видит игрок | Доступные переходы |
| --- | --- | --- |
| `MENU` | Название, лесная иллюстрация, герой, подсказки клавиш и кнопка «Играть» | «Играть» начинает новую попытку |
| `PLAYING` | Игровое поле, три сердца слева, «Монеты: N / 20» и кнопка паузы справа | Escape или кнопка открывают паузу. Финиш и поражение открывают соответствующие результаты |
| `PAUSED` | Затемнённая сцена и диалог паузы | Escape или «Продолжить» возобновляют текущую попытку. «Начать заново» сбрасывает уровень. «Главное меню» завершает попытку |
| `GAME_OVER` | Диалог «Игра окончена» | «Повторить» начинает новую попытку. «Главное меню» возвращает на стартовый экран |
| `VICTORY` | Диалог «Победа!», число монет и время в формате `M:SS` | «Играть снова» начинает новую попытку. «Главное меню» возвращает на стартовый экран |

На паузе останавливаются физика, враги, снаряды, игровые анимации и таймер. Итоговое время фиксируется при завершении попытки и не включает время на паузе. Новая попытка восстанавливает точку старта, три сердца, все монеты и всех врагов, очищает снаряды и сбрасывает время.

## 3. Управление и физика

| Клавиша | Действие |
| --- | --- |
| ← / → | Ускорение влево / вправо, поворот героя в сторону движения |
| ↑ | Одинарный прыжок |
| Пробел | Выстрел в сторону взгляда. Удержание повторяет выстрелы по мере готовности |
| Escape | Пауза и возобновление |

Аркадная физика использует фиксированные логические координаты. Противоположные направления при одновременном нажатии дают нулевой ввод. При отпускании клавиш герой плавно тормозит. Столкновения с землёй и платформами обрабатывает Arcade Physics. Клавиши игрового управления захватываются, чтобы стрелки и пробел не прокручивали страницу.

| Параметр | Значение |
| --- | --- |
| Максимальная скорость обычного движения | 250 единиц/с |
| Горизонтальный разгон / торможение | 1600 / 1750 единиц/с² |
| Гравитация | 1000 единиц/с² |
| Начальная скорость прыжка | 520 единиц/с вверх |
| Прыжок после схода с края | до 100 мс |
| Буфер прыжка перед приземлением | до 100 мс |

Прыжок расходуется один раз до следующего приземления. Короткое нажатие стрелки вверх сохраняется между кадрами. Визуальные состояния героя включают стойку, бег, подъём, падение, выстрел, получение урона и смерть.

## 4. Бой, здоровье и монеты

- **Здоровье.** Попытка начинается с трёх сердец. Контакт с шипами или живым врагом снимает одно сердце. Если здоровье осталось, герой отталкивается от источника урона, мигает и на 1000 мс становится неуязвимым. Начальная скорость отбрасывания составляет 280 единиц/с по горизонтали и вверх. Управление движением ограничено на первые 190 мс.
- **Поражение.** При нуле сердец останавливается физика и проигрывается анимация смерти, после которой появляется диалог поражения. Падение ниже границы мира завершает попытку сразу, при любом остатке здоровья.
- **Стрельба.** Боезапас не ограничен. Между выстрелами должно пройти 350 мс. Снаряд летит горизонтально со скоростью 650 единиц/с и может быть выпущен на земле и в воздухе. При попадании в твёрдую поверхность или врага снаряд деактивируется. Снаряды также удаляются за границей мира или вдали от героя. Пул ограничен 12 объектами.
- **Слизни.** Восемь наземных врагов движутся по заданным участкам со скоростью 52 единицы/с, разворачиваются у границ патруля и не покидают опору.
- **Летучие мыши.** Четыре врага патрулируют по горизонтали со скоростью 86 единиц/с, плавно меняют высоту и машут крыльями.
- **Попадание по врагу.** Один снаряд уничтожает любого врага. Враг удаляется из физической сцены и появляется снова только в новой попытке. Выстрел, попадание и уничтожение сопровождаются частицами.
- **Монеты.** На карте ровно 20 монет. Каждая собирается автоматически при контакте, засчитывается один раз за попытку, исчезает и запускает эффект частиц. Монеты расположены на земле и над платформами.

## 5. Уровень и представление

Первая глава имеет идентификатор `fernwood`. Четыре участка обозначены табличками «Тропа папоротников», «Мшистая ложбина», «Крылатые скалы» и «Солнечная опушка».

| Элемент | Реализация |
| --- | --- |
| Земля | 20 участков с верхней поверхностью на Y = 610 |
| Пропасти | 19 промежутков шириной от 110 до 170 единиц |
| Платформы | 27 статичных уступов на двух высотах |
| Шипы | 9 групп с отдельными зонами урона |
| Старт | X = 180, Y = 552 |
| Финиш | Зона шириной 95 и высотой 165 единиц у правого края карты |
| Победа | Срабатывает при касании финишной зоны независимо от монет и оставшихся врагов |

Поле имеет логическое разрешение 1280 × 720. При изменении окна сохраняется формат 16:9, физические размеры карты не меняются. Камера плавно следует за героем по горизонтали, использует зону свободного перемещения и ограничена краями карты. Горы и дальний пейзаж прокручиваются медленнее ближних деревьев. Окружение, герой, враги и предметы оформлены в мультяшном стиле с оригинальной SVG-графикой.

## 6. Архитектура

| Путь | Ответственность |
| --- | --- |
| `src/main.tsx` | Запуск React |
| `src/app/App.tsx`, `App.module.css` | Меню, HUD, диалоги результатов, масштабирование оболочки и подключение Phaser |
| `src/game/session.ts` | Состояния попытки, допустимые переходы, здоровье, сбор монет, таймер, ограничение частоты стрельбы и подписка React |
| `src/game/config.ts` | Разрешение, параметры движения и боя |
| `src/game/level.ts` | Типизированная схема `Level` и конфигурация главы `fernwood` |
| `src/game/LevelScene.ts` | Загрузка текстур, физический мир, столкновения, снаряды, частицы, камера и запуск Phaser |
| `src/game/entities.ts` | Управление игроком, состояния спрайта и поведение патрулей |
| `src/game/scenery.ts` | Отрисовка земли, шипов, декораций и слоёв параллакса |
| `src/assets/` | Лесной фон, иконка и исходники SVG-кадров |

Стек проекта — React 19, TypeScript в строгом режиме, Vite, Phaser 3 с Arcade Physics и CSS Modules. React подписывается на типизированный снимок состояния попытки через `useSyncExternalStore`. Игровой цикл работает в Phaser. React получает обновления при изменениях здоровья, счёта и фазы. Игровой движок загружается при входе в игру. Повтор перезапускает сцену. При выходе в меню подписки отключаются, экземпляр Phaser уничтожается.

Для второй главы нужно создать конфигурацию `Level`, передать выбранную главу в `mountGame` и брать название главы и общее число монет из той же конфигурации в React. Если тема и разбивка на участки отличаются, потребуется настроить оформление и таблички в `scenery.ts`.

## 7. Запуск и проверки

```sh
npm ci
npm run dev
npm run build
npm run preview
npm test
npx playwright install chromium
npm run test:e2e
```

Для установленного Google Chrome можно запустить `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`. E2E запускает отдельный локальный сервер Vite в режиме `e2e`. В этом режиме тесты могут читать координаты, скорость и состояние сцены через `window.forestObserve`. Движение, прыжки, стрельба и переходы выполняются обычными клавишами и кнопками. Production-сборка этот интерфейс не публикует.

| Проверка | Покрытие |
| --- | --- |
| Vitest, 10 тестов | Здоровье, неуязвимость, поражение, монеты, частота выстрелов, пауза, сброс попытки, победа без монет и геометрия уровня |
| Playwright, 4 сценария | Меню и управление, прыжок без двойного прыжка, пауза и масштабирование, перезапуск, поведение врагов и попадание, падение, полный маршрут до флага, урон от шипов |
| Production в Chrome | Запуск, сбор монеты, пауза и возобновление, отсутствие ошибок в консоли и тестового интерфейса |

Результаты отражают проведённую ранее проверку Chrome. Firefox, Safari и Edge в этой проверке не запускались. Playwright MCP для тестов проекта не требуется.
